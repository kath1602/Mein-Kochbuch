MEIN KOCHBUCH – INSTALLIERBARE WEB-APP

Diese Dateien sind eine PWA-fähige Version deines Kochbuchs.

WICHTIG:
Eine HTML-Datei allein kann auf dem iPhone nicht als installierbare App veröffentlicht werden. Für „Zum Home-Bildschirm“ mit Offline-Cache muss die App über HTTPS erreichbar sein. Diese ZIP-Datei enthält die fertigen Web-Dateien, ist aber noch nicht im Internet veröffentlicht.

VERÖFFENTLICHUNG MIT GITHUB PAGES (kostenlos):
1. Am Computer GitHub öffnen und ein kostenloses Konto erstellen/anmelden.
2. Ein neues Repository erstellen, z. B. mein-kochbuch. Für GitHub Pages muss es öffentlich sein.
3. Alle Dateien aus diesem Ordner hochladen (index.html, manifest.webmanifest, sw.js, icon.svg).
4. Im Repository Settings > Pages öffnen.
5. Bei Build and deployment „Deploy from a branch“ wählen, Branch „main“, Ordner „/(root)“, speichern.
6. Nach der Veröffentlichung die angezeigte https://…github.io/…-Adresse in Safari auf dem iPhone öffnen.
7. Teilen > Zum Home-Bildschirm > Hinzufügen.

DATENSCHUTZ & SPEICHERUNG:
Rezepte werden in localStorage des Browsers gespeichert. Sie bleiben auf diesem Gerät und in diesem Browserprofil; sie werden nicht automatisch zwischen Geräten synchronisiert. Browserdaten löschen kann Rezepte entfernen. Nutze regelmäßig „Backup exportieren“ im Kochbuch und bewahre die JSON-Datei sicher auf.

INSTAGRAM/TIKTOK:
Links können im Kochbuch gespeichert werden. Das automatische Auslesen von Rezepttexten aus Instagram/TikTok ist wegen Login- und Plattformbeschränkungen nicht zuverlässig. Caption/Zutaten können manuell in die Rezeptfelder kopiert werden.
